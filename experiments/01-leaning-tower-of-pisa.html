Experiment 01: The Leaning Tower of Pisa

How Newton’s Second Law governs falling objects in a vacuum and in air

1. The Physics Problem & Analytical Laws

Legend holds that around 1589, Galileo Galilei dropped two spheres of different masses from the top of the Leaning Tower of Pisa (\(H = 56\text{ m}\)) to test whether heavier objects fall faster than lighter ones. Nearly four centuries later, in 1971, Apollo 15 astronaut David Scott repeated the experiment on the airless Moon using a geology hammer and a falcon feather—and both hit the lunar surface at the exact same instant.

Why do a hammer and a feather tie in a vacuum, yet separate dramatically in Earth’s atmosphere? The answer lies in Newton’s Second Law of Motion:

\[F_{\text{net}} = m \cdot a \quad \Longrightarrow \quad a = \frac{F_{\text{net}}}{m}\]

where \(F_{\text{net}}\) is the total net force acting on the object (in Newtons, \(\text{N}\)), \(m\) is its mass (\(\text{kg}\)), and \(a\) is its downward acceleration (\(\text{m/s}^2\)).

Case A: Free Fall in a Vacuum (Gravity Only)

In a vacuum, the only force pulling the object downward is gravity, \(F_g = m g\), where \(g \approx 9.81\text{ m/s}^2\) near Earth’s surface. Substituting this into Newton’s Second Law:

\[a = \frac{F_g}{m} = \frac{m g}{m} = g\]

Notice that mass \(m\) cancels out completely. Because every object accelerates at the exact same rate \(g\), velocity \(v(t)\) and distance fallen \(d(t)\) follow clean analytical formulas:

\[v(t) = g t \qquad \text{and} \qquad d(t) = \frac{1}{2} g t^2\]

From a \(H = 56\text{ m}\) tower, both the hammer and the feather land in:

\[t_{\text{land}} = \sqrt{\frac{2H}{g}} = \sqrt{\frac{2(56)}{9.81}} \approx 3.38\text{ s}\]

Case B: Falling Through Air (Gravity + Air Resistance)

In Earth’s atmosphere, a falling object collides with air molecules, creating an upward aerodynamic drag force \(F_d\) that grows with the square of its speed:

\[F_d = \frac{1}{2} \rho C_d A v^2\]

  • \(\rho\): air density (\(\approx 1.225\text{ kg/m}^3\) at sea level)
  • \(C_d\): dimensionless drag coefficient (shape roughness)
  • \(A\): cross-sectional area facing the airflow (\(\text{m}^2\))

Applying Newton’s Second Law now gives:

\[a(t) = \frac{F_g - F_d}{m} = g - \frac{\rho C_d A}{2m} v(t)^2\]

Here, mass no longer cancels out. For a light feather with a broad surface area, \(\frac{\rho C_d A}{2m}\) is large—so \(F_d\) quickly grows until it equals gravity (\(F_d = m g\)). At that point, net force and acceleration drop to zero (\(a = 0\)), and the feather stops speeding up, drifting downward at a constant terminal velocity:

\[v_t = \sqrt{\frac{2 m g}{\rho C_d A}}\]

2. The Simulation Method: Euler–Cromer Integration

Because air drag changes continuously as velocity changes, we let the computer simulate the fall in tiny time slices of \(\Delta t = 0.01\text{ seconds}\) using the Euler–Cromer method:

  1. Calculate forces & acceleration at the current step \(i\): \[a_i = g - \frac{\rho C_d A}{2m} v_i^2\]
  2. Update velocity over the tiny time slice \(\Delta t\): \[v_{i+1} = v_i + a_i \Delta t\]
  3. Update altitude using the newly updated velocity: \[y_{i+1} = y_i - v_{i+1} \Delta t\]

Repeating these steps reconstructs the entire trajectory from the top of the tower (\(y = H\)) to the ground (\(y = 0\text{ m}\)).

function debounce(view, delay = 250) {
  return Generators.observe(notify => {
    let timer = null;
    const onInput = () => {
      clearTimeout(timer);
      timer = setTimeout(() => notify(view.value), delay);
    };
    view.addEventListener("input", onInput);
    notify(view.value);
    return () => view.removeEventListener("input", onInput);
  });
}

viewof hammer_mass_ui = Inputs.range([0.2, 10.0], {value: 1.5, step: 0.1, label: "Hammer Mass (kg)"})

  ]),
  {value: 9.81, label: "Gravity g"}

"""
In Silico Physics Lab — Experiment 01: The Leaning Tower of Pisa
Self-contained 1:1 real-time simulation of a falling hammer and feather.

Requirements:
    pip install numpy matplotlib
"""

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

# 1. Physical Constants & Object Properties (Edit these to experiment!)
TOWER_HEIGHT = 56.0      # m
GRAVITY = 9.81           # m/s^2 (Earth: 9.81, Moon: 1.62, Mars: 3.72)
AIR_DENSITY = 1.225      # kg/m^3

HAMMER = {"mass": 1.50, "area": 0.008, "cd": 0.80}
FEATHER = {"mass": 0.002, "area": 0.004, "cd": 1.20}

DT = 0.01                # Numerical time step (s)
FPS = 20                 # Playback frame rate (20 FPS = 50 ms per frame)

# Automatically estimate enough simulation time for the feather to land
v_term_feather = np.sqrt(
    2.0 * FEATHER["mass"] * GRAVITY / (AIR_DENSITY * FEATHER["cd"] * FEATHER["area"])
)
T_MAX = float(
    np.ceil(np.sqrt(2.0 * TOWER_HEIGHT / GRAVITY) + (TOWER_HEIGHT / v_term_feather) + 1.0)
)


def simulate_fall(mass: float, area: float, cd: float, rho: float) -> dict:
    """Integrate Newton's 2nd Law (F_net = m*g - F_drag) via Euler-Cromer."""
    steps = int(np.ceil(T_MAX / DT)) + 1
    t = np.linspace(0.0, (steps - 1) * DT, steps)
    y = np.zeros(steps)
    v = np.zeros(steps)
    a = np.zeros(steps)

    y[0] = TOWER_HEIGHT
    a[0] = GRAVITY
    drag_k = 0.5 * rho * cd * area / mass

    for i in range(steps - 1):
        if y[i] <= 0.0:
            y[i + 1], v[i + 1], a[i + 1] = 0.0, 0.0, 0.0
            continue

        a_curr = GRAVITY - drag_k * (v[i] ** 2)
        a[i] = a_curr
        v_next = v[i] + a_curr * DT
        y_next = y[i] - v_next * DT

        if y_next <= 0.0:
            y[i + 1], v[i + 1], a[i + 1] = 0.0, 0.0, 0.0
        else:
            y[i + 1] = y_next
            v[i + 1] = v_next

    return {"t": t, "y": y, "d": TOWER_HEIGHT - y, "v": v, "a": a}


if __name__ == "__main__":
    ham_vac = simulate_fall(HAMMER["mass"], HAMMER["area"], 0.0, 0.0)
    fea_vac = simulate_fall(FEATHER["mass"], FEATHER["area"], 0.0, 0.0)
    ham_air = simulate_fall(HAMMER["mass"], HAMMER["area"], HAMMER["cd"], AIR_DENSITY)
    fea_air = simulate_fall(FEATHER["mass"], FEATHER["area"], FEATHER["cd"], AIR_DENSITY)

    fig, (ax_drop, ax_vel) = plt.subplots(1, 2, figsize=(10, 5))
    ax_drop.set_xlim(0, 4)
    ax_drop.set_ylim(0, TOWER_HEIGHT * 1.14)
    ax_drop.axvline(2.0, color="gray", linestyle="--")
    ax_drop.set_xticks([1.0, 3.0])
    ax_drop.set_xticklabels(["Vacuum", "Atmosphere"])
    ax_drop.set_ylabel("Altitude (m)")
    ax_drop.set_title(f"Leaning Tower of Pisa Drop ({TOWER_HEIGHT:.0f} m)")

    p_hv, = ax_drop.plot([0.7], [TOWER_HEIGHT], "s", markersize=11, color="#0B1F3A", label="Hammer")
    p_fv, = ax_drop.plot([1.3], [TOWER_HEIGHT], "^", markersize=11, color="#1C939A", label="Feather (Vacuum)")
    p_ha, = ax_drop.plot([2.7], [TOWER_HEIGHT], "s", markersize=11, color="#0B1F3A")
    p_fa, = ax_drop.plot([3.3], [TOWER_HEIGHT], "^", markersize=11, color="#D97706", label="Feather (Air)")
    time_badge = ax_drop.text(
        2.0, TOWER_HEIGHT * 1.06, "t =  0.00 s (1.0× Real-Time)",
        ha="center", va="center", fontsize=9.5, fontweight="bold", color="white",
        bbox=dict(boxstyle="round,pad=0.3", facecolor="#0B1F3A", edgecolor="none"),
    )
    ax_drop.legend(loc="lower center")

    t = ham_vac["t"]
    ax_vel.set_xlim(0, T_MAX)
    ax_vel.set_ylim(0, np.max(ham_vac["v"]) * 1.15)
    ax_vel.set_xlabel("Time (s)")
    ax_vel.set_ylabel("Downward Speed (m/s)")
    ax_vel.set_title("Velocity vs. Time")
    ax_vel.grid(True, linestyle="--", alpha=0.5)

    l_vac, = ax_vel.plot([], [], "--", color="#0B1F3A", label="Vacuum (Both)")
    l_ha, = ax_vel.plot([], [], "-", color="#0B1F3A", label="Hammer (Air)")
    l_fa, = ax_vel.plot([], [], "-", color="#D97706", label="Feather (Air)")
    ax_vel.legend()

    fig.tight_layout()

    # Lock frame stride and interval to 1:1 real-time (20 FPS -> 50 ms per 0.05 s step)
    step_stride = max(1, int(round(1.0 / (FPS * DT))))
    interval_ms = int(round(step_stride * DT * 1000))
    frames = np.arange(0, len(t), step_stride)

    def animate(idx):
        p_hv.set_data([0.7], [ham_vac["y"][idx]])
        p_fv.set_data([1.3], [fea_vac["y"][idx]])
        p_ha.set_data([2.7], [ham_air["y"][idx]])
        p_fa.set_data([3.3], [fea_air["y"][idx]])
        time_badge.set_text(f"t = {t[idx]:5.2f} s (1.0× Real-Time)")
        l_vac.set_data(t[: idx + 1], ham_vac["v"][: idx + 1])
        l_ha.set_data(t[: idx + 1], ham_air["v"][: idx + 1])
        l_fa.set_data(t[: idx + 1], fea_air["v"][: idx + 1])
        return p_hv, p_fv, p_ha, p_fa, time_badge, l_vac, l_ha, l_fa

    ani = FuncAnimation(fig, animate, frames=frames, interval=interval_ms, blit=False)
    plt.show()
